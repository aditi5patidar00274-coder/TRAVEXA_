TRAVEXA – Smart Travel Planner
A modern web-based travel booking platform built using Python Flask and MySQL that allows users to search, view, and book Flights, Trains, and Buses from a single interface.

🚀 Features :-

🔐 User Authentication (Login & Signup)
✈️ Flight Search using Amadeus API
🚆 Train Search using RapidAPI IRCTC API
🚌 Bus Booking with realistic mock data
💳 Payment System with:
E-Wallet
Card (Simulated)
UPI (Simulated)
Net Banking (Simulated)
📒 My Bookings Management
❌ One-click Ticket Cancellation
💰 Automated Refund System
👛 Integrated E-Wallet
📊 MySQL Database Integration
🔄 Session Management using Flask
